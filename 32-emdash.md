Le 1er avril 2026, l'équipe de développement de CloudFlare a présenté un nouveau CMS: **EmDash**. 

Ce CMS est basé sur Astro, un framework JavaScript. Il est présenté comme "un CMS sécurisé contruit sur Astro pour être le successeur spirituel de WordPress". Il utilise JavaScript au lieu du PHP.

On peut le déployer sur des hébergements comme CloudFlare, Netlify ou Vercel.

- 1er avril 2026: [Le post d'annonce](https://blog.cloudflare.com/emdash-wordpress/)
- 28 septembre 2026: [sortie de la version 1.0](https://emdashcms.com/blog/emdash-1-0). Voir la vidéo de lancement [sur X.com](https://x.com/EmDashCMS/status/2104568622337192369).

Le site dédié : [https://emdashcms.com/](https://emdashcms.com/)

Le "Playground" qui permet de le tester: [https://try.emdashcms.com/playground](https://try.emdashcms.com/playground)

Objectif de ce projet:

- Tester la création d'un site avec EmDash.
- Documenter le processus.
- Vérifier ce que l'on peut faire gratuitement, et ce que coûte p.ex. l'ajout d'un nom de domaine.
- Présenter ce travail à la classe.

Explicatifs de terminologie Cloudflare:

- D1: un système de base de donnée (comme SQL), c'est le contenu.
- R2: système de stockage de données, ce sont les fichiers images. La limite du stockage gratuit est de 10 GB.
